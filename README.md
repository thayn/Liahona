# Liahona

Interactive "Liahona" balls for a youth camp (12 + 1 spare). Each one is a 175 mm 3D-printed ball with a 4" round touchscreen, compass, GPS, NFC reader, LoRa radio link to the leaders' base station, and a Hebrew text band lit from inside.

| Folder | What's in it |
|---|---|
| [`firmware/`](firmware/) | ESP-IDF firmware for the Waveshare ESP32-P4-WIFI6-Touch-LCD-4C. Its README covers building, flashing and the self-test. |
| [`cad/`](cad/) | build123d model of the ball (`liahona.py`, one settings block). `out/` has the 3MF files for printing, plus renders. |
| [`docs/`](docs/) | CAD spec and the Liahona Manager architecture (web plus offline journey manager). |

## Quick start
- **Firmware:** in VS Code (ESP-IDF extension, v6.1), open `firmware/`, set the target to `esp32p4`, then Build, Flash and Monitor.
- **Print:** load the `.3mf` files from `cad/out/` into Bambu Studio.
- **Regenerate the CAD:** in `cad/`, run `python liahona.py`. This writes STEP, STL and 3MF to `cad/out/`. STEP and STL aren't committed because they're large and regenerated by the script. The Hebrew band uses FreeSerif Bold (`fonts-freefont-ttf`).
